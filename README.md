# KUZAT

**KUZAT** — универсальный видеоплеер для просмотра видео из YouTube, VK Видео и прямых видеоисточников.

> Цель проекта: сделать удобное приложение для **просмотра**, а не скачивания видео.

## Этап 3 — Настоящее качество видео

**Статус: 🔴 не готово**

Это важный этап. Простое меню с надписями 1080p/720p ещё не означает переключение качества.

### HLS / DASH

- [ ] Получать доступные video tracks.
- [ ] Показывать реальные доступные разрешения.
- [ ] Режим **Auto**.
- [ ] Ручной выбор 144p/240p/360p/480p/720p/1080p — только если поток реально содержит такую дорожку.
- [ ] Переключать дорожку без лишней перезагрузки.
- [ ] Сохранять текущую позицию после переключения.

### YouTube

- [ ] Не обещать принудительный выбор качества, если его не разрешает официальный YouTube IFrame API.
- [ ] Показывать понятное состояние: **Auto — качество выбирает YouTube**.

### VK Видео

- [ ] Получать доступные качества из resolver/API.
- [ ] Если VK даёт HLS с несколькими вариантами — использовать его для Auto/ABR.
- [ ] Если есть только отдельные MP4 — переключать только реально доступные варианты.

**Результат этапа:** качество в меню действительно влияет на поток, а не является декоративной кнопкой.
