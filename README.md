# KUZAT

Universal video player for YouTube, VK Видео and direct video sources.

## Current player

- YouTube links through the official YouTube IFrame player
- Direct MP4 / HLS / M3U8 playback
- Dark KUZAT interface
- Search / YouTube / VK Видео top tabs
- Главная / Библиотека / Настройки bottom navigation
- Viewer-only design: no download button
- Quality menu prepared for Auto and common resolutions

## Next steps

1. Add VK Video resolver/player integration.
2. Add real HLS/DASH track selection for 144p–1080p where the source provides those renditions.
3. Add fullscreen, speed and playback-position persistence.
